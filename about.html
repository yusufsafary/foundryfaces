About Foundry Faces

Last updated · 11 November 2026

Foundry Faces is a collection of 11,111 pixel faces on BNB Chain, built for a Binance Agentic Wallet era. Each face is an ERC-721 token with a seed stored on chain at mint. Artwork renders from that seed, so a face appears instantly at mint and never changes after.

How minting works

This website is read only. It has no wallet connection, no signing, and no checkout. Minting runs through a visitor's own agent in Binance Agentic Wallet, following instructions in a public skill file. A first mint per wallet is free and gated by two checks: ownership of an Agent ID NFT and a short arithmetic question served by contract itself.

Paid mints follow a stepped price schedule in BNB. All mint proceeds move to a project wallet inside same transaction as a mint. Contract is designed to hold no spendable balance.
